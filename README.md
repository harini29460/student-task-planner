# Student Task Planner

A web-based Student Task and Study Planner designed to help students organize their academic tasks and manage their study activities efficiently.

## Features

* Add and manage student tasks
* Organize study activities
* Simple and user-friendly interface
* Task planning and tracking
* Web-based application

## Technologies Used

* PHP
* HTML
* CSS
* MySQL

## Project Structure

```text
student-task-planner/
│
├── css/
│   └── style.css
│
├── index.php
│
└── README.md
```

## How to Run

1. Install XAMPP.
2. Start **Apache** and **MySQL** from the XAMPP Control Panel.
3. Copy the project folder into the `htdocs` folder.
4. Open a browser.
5. Visit:

```text
http://localhost/student-task-planner/
```

## Purpose

The main purpose of this project is to provide students with a simple web application for organizing academic tasks and study activities in one place.
